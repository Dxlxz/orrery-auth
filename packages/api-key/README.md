# Orrery Auth API Key Plugin

API Key plugin for [Orrery Auth](https://www.orrery-auth.com) — manage API keys for your users.

## Installation

```bash
npm install @orrery/api-key
```

## Documentation

For full documentation, visit [orrery-auth.com/docs/plugins/api-key](https://www.orrery-auth.com/docs/plugins/api-key).
