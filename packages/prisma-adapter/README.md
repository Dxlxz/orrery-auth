# Orrery Auth Prisma Adapter

Prisma adapter for [Orrery Auth](https://www.orrery-auth.com).

## Installation

```bash
npm install @orrery/prisma-adapter
```

## Documentation

For full documentation, visit [orrery-auth.com/docs/adapters/prisma](https://www.orrery-auth.com/docs/adapters/prisma).
