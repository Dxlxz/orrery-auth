# Orrery Auth MongoDB Adapter

MongoDB adapter for [Orrery Auth](https://www.orrery-auth.com).

## Installation

```bash
npm install @orrery/mongo-adapter
```

## Documentation

For full documentation, visit [orrery-auth.com/docs/adapters/mongodb](https://www.orrery-auth.com/docs/adapters/mongodb).
