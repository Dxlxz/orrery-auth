# Orrery Auth Drizzle Adapter

Drizzle ORM adapter for [Orrery Auth](https://www.orrery-auth.com).

## Installation

```bash
npm install @orrery/drizzle-adapter
```

## Documentation

For full documentation, visit [orrery-auth.com/docs/adapters/drizzle](https://www.orrery-auth.com/docs/adapters/drizzle).
