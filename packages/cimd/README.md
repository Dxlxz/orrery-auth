# Orrery Auth CIMD Plugin

Client ID Metadata Document draft-02 plugin for [Orrery Auth](https://www.orrery-auth.com): unauthenticated client discovery over HTTPS. An explicit metadata profile applies the draft-00 requirements pinned by [MCP 2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/basic/authorization/client-registration#client-id-metadata-documents).

## Installation

```bash
npm install @orrery/cimd
```

## Documentation

For full documentation, visit [orrery-auth.com/docs/plugins/cimd](https://www.orrery-auth.com/docs/plugins/cimd).
