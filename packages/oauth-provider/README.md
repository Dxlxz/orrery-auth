# Orrery Auth OAuth Provider Plugin

OAuth provider plugin for [Orrery Auth](https://www.orrery-auth.com) — turn your application into an OAuth 2.0 provider.

## Installation

```bash
npm install @orrery/oauth-provider
```

## Documentation

For full documentation, visit [orrery-auth.com/docs/plugins/oauth-provider](https://www.orrery-auth.com/docs/plugins/oauth-provider).
