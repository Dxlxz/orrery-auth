# Orrery Auth Stripe Plugin

Stripe plugin for [Orrery Auth](https://www.orrery-auth.com) — integrate Stripe billing with your authentication system.

## Installation

```bash
npm install @orrery/stripe
```

## Documentation

For full documentation, visit [orrery-auth.com/docs/plugins/stripe](https://www.orrery-auth.com/docs/plugins/stripe).
