# Orrery Auth SSO Plugin

Single Sign-On plugin for [Orrery Auth](https://www.orrery-auth.com) — add SAML and OIDC enterprise SSO to your application.

## Installation

```bash
npm install @orrery/sso
```

## Documentation

For full documentation, visit [orrery-auth.com/docs/plugins/sso](https://www.orrery-auth.com/docs/plugins/sso).
