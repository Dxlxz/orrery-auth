# Orrery Auth Telemetry

Telemetry package for [Orrery Auth](https://www.orrery-auth.com) — anonymous usage analytics to help improve the framework.

## Installation

```bash
npm install @orrery/telemetry
```

## Documentation

For full documentation, visit [orrery-auth.com](https://www.orrery-auth.com).
