# Orrery Auth Kysely Adapter

Kysely adapter for [Orrery Auth](https://www.orrery-auth.com).

## Installation

```bash
npm install @orrery/kysely-adapter
```

## Documentation

For full documentation, visit [orrery-auth.com/docs/adapters/kysely](https://www.orrery-auth.com/docs/adapters/kysely).
