# Orrery Auth SCIM Plugin

`@orrery/scim` adds an inbound System for Cross-domain Identity Management (SCIM) 2.0 service to [Orrery Auth](https://www.orrery-auth.com). Directory services can provision isolated Users, Groups, and direct Group memberships through bearer-authenticated connections.

The plugin supports a focused subset of the resource model in [RFC 7643](https://www.rfc-editor.org/rfc/rfc7643) and the protocol in [RFC 7644](https://www.rfc-editor.org/rfc/rfc7644).

## Installation

```bash
pnpm add @orrery/scim
```

## Documentation

For setup, Groups and custom roles, and the protocol reference, visit [orrery-auth.com/docs/plugins/scim](https://www.orrery-auth.com/docs/plugins/scim).
