## Orrery Auth

Orrery Auth is a framework-agnostic authentication (and authorization) framework for TypeScript. It provides a comprehensive set of features out of the box and includes a plugin ecosystem that simplifies adding advanced functionalities with minimal code in a short amount of time. Whether you need 2FA, multi-tenant support, or other complex features, it lets you focus on building your actual application instead of reinventing the wheel.

### Why Orrery Auth

Authentication in the TypeScript ecosystem is a half-solved problem. Other open-source libraries often require a lot of additional code for anything beyond basic authentication. Rather than just pushing third-party services as the solution, I believe we can do better as a community—hence, Orrery Auth.

If you discover a security vulnerability within Orrery Auth, please report it via [GitHub Security Advisories](https://github.com/Dxlxz/orrery-auth/security/advisories/new).

All reports will be promptly addressed, and you'll be credited accordingly.
